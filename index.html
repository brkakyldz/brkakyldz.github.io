IssuePilot

Investigates every new GitHub issue with Claude Code and posts one comment: the likely cause, where it is in the code, a suggested fix and what it could not verify. Every file, line and quote it cites is checked against the code before anything is posted.Her yeni GitHub issue’sunu Claude Code ile inceliyor ve tek bir yorum bırakıyor: olası neden, kodda nerede olduğu, bir çözüm önerisi ve doğrulayamadığı şeyler. Yorumda geçen her dosya, satır ve alıntı, paylaşılmadan önce koda karşı kontrol ediliyor.

Hotel Operations Agent

An AI concierge for a simulated hotel. Guests write in any language, the agent turns requests into real records, the hotel’s rules run in code, and anything that needs a manager waits for one. When the hotel changes, the guest is told without asking.Kurgusal bir otel için AI concierge. Misafir istediği dilde yazıyor, agent talebi otelin kayıtlarına işliyor, otelin kuralları kodda çalışıyor, yönetici onayı gereken iş yöneticiyi bekliyor. Otelde bir şey değiştiğinde misafir sormadan haber alıyor.

AI News Digest

The day’s AI news from sixteen feeds, deduplicated, summarised and ranked into one bulletin in English and Turkish. Polling the feeds is free; a bulletin costs money, so it waits for someone to press Run.On altı kaynaktan günün AI haberleri: tekrarlar ayıklanıyor, haberler özetlenip sıralanıyor ve İngilizce ile Türkçe tek bir bülten çıkıyor. Kaynak taraması ücretsiz; bülten para harcadığı için birinin Run’a basmasını bekliyor.

AboutHakkımda

I build agent systems end to end in Python, with the OpenAI Agents SDK, LangGraph and the OpenAI and Anthropic APIs. I keep the model’s part small and the rules in code, and I don’t call a system done until an evaluation says so. Every project here is open source.Agent sistemlerini Python’la, OpenAI Agents SDK, LangGraph ve OpenAI ile Anthropic API’leriyle uçtan uca kuruyorum. Modelin payını küçük, kuralları kodda tutuyorum; bir değerlendirme göstermeden bir sisteme “bitti” demiyorum. Buradaki projelerin hepsinin kodu açık.
