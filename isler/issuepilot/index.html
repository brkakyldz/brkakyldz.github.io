IssuePilot

Every new GitHub issue gets one investigated comment: the likely cause, where it is in the code, a suggested fix and what could not be verified. It runs Claude Code in GitHub Actions on your own Claude subscription, and every file, line and quote it cites is checked against the code before anything is posted.Her yeni GitHub issue’su incelenmiş tek bir yorum alıyor: olası neden, kodda nerede olduğu, bir çözüm önerisi ve doğrulanamayan noktalar. Claude Code’u GitHub Actions içinde, kendi Claude aboneliğinle çalıştırıyor; yorumda geçen her dosya, satır ve alıntı paylaşılmadan önce koda karşı kontrol ediliyor.

In shortKısaca

Problem
Before anyone writes a fix, a new issue usually means finding the relevant code, tracing the cause and deciding where to start.Bir düzeltme yazılmadan önce yeni bir issue çoğu zaman ilgili kodu bulmayı, nedenin izini sürmeyi ve nereden başlanacağına karar vermeyi gerektiriyor.
What it doesNe yapıyor
Within a minute or two the issue gets one comment with the cause, links to the lines, a fix and what it is unsure of. Copy one workflow file and add a token: there is no server.Bir iki dakika içinde issue’ya nedeni, satırların bağlantılarını, bir çözümü ve emin olunmayan noktaları içeren tek bir yorum geliyor. Kurulum tek bir workflow dosyası ve bir token; sunucu yok.
Key decisionTemel karar
The model never posts. Claude Code investigates with a read-only token and no tool that writes; a second job with no AI checks every citation on a fresh checkout and scans for secrets before publishing.Model hiçbir şey paylaşmıyor. Claude Code salt okunur bir token’la ve yazan hiçbir araç olmadan inceliyor; AI’sız ikinci bir job her alıntıyı temiz bir checkout üzerinde kontrol ediyor ve yayımlamadan önce sır taraması yapıyor.
